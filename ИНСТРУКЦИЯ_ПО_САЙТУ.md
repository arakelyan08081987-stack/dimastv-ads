## 🗂 Состав файлов в этой папке

- **`index.html`** — главный и единственный файл сайта (содержит разметку, стили и скрипты калькулятора и языков).
- **`avatar.png`** — логотип канала с горящими глазами (отображается в шапке и первом экране).
- **`update_site.bat`** — скрипт в 1 клик для упаковки архива на рабочий стол и отправки изменений в GitHub.
- **`SITE_DATA.json`** — паспорт данных (все актуальные цены, статистика, охваты и ссылки в одном месте).
- **`ШАБЛОНЫ_ОТВЕТОВ_РЕКЛАМОДАТЕЛЯМ.txt`** — готовые тексты ответов для спонсоров на русском и английском.

## ✏️ Как вносить изменения в `index.html`

Файл `index.html` можно открыть в любом текстовом редакторе (Блокнот, VS Code, Notepad++).

### 1. Как изменить цены на рекламу:
Цены указаны в двух местах:

1. **В карточках прайс-листа (визуальное отображение)** — найдите поиском `price-tag`:
   - Pre-roll: `500 $` (зачеркнуто `1 000 $`)
   - Post-roll: `150 $` (зачеркнуто `300 $`)
   - Сообщество YouTube: `250 $` (зачеркнуто `500 $`)
   - TikTok: `100 $` (зачеркнуто `200 $`)
   - Discord: `100 $` (зачеркнуто `200 $`)
   - Steam: `50 $` (зачеркнуто `100 $`)

2. **В интерактивном калькуляторе (для расчёта суммы)** — найдите поиском `calcState`:
   ```javascript
   const calcState = {
     pre_roll: { active: true, price: 500, ... },
     post_roll: { active: false, price: 150, ... },
     yt_community: { active: false, price: 250, ... },
     tiktok: { active: false, price: 100, ... },
     discord: { active: false, price: 100, ... },
     steam: { active: false, price: 50, ... }
   };
   ```
   Просто поменяйте цифру в поле `price`.

### 4. Как менять тексты на русском и английском (i18n):
В самом низу `index.html` найдите блок:
```javascript
const i18n = {
  ru: { ... },
  en: { ... }
};
```
Здесь хранятся все переводы. Если меняете текст на русском — не забудьте продублировать перевод в блоке `en`.

## 🚀 Как выгрузить изменения на рабочий сайт

После сохранения изменений в `index.html`:

### Способ 1 (через скрипт):
Дважды кликните по файлу **`update_site.bat`** в этой папке.  
Он автоматически:
1. Создаст свежий архив `dimastv-site.zip` на вашем Рабочем столе.
2. Сохранит изменения в репозитории GitHub.
3. Откроет страницу деплоя Netlify в браузере.

### Способ 2 (загрузка на Netlify за 5 секунд):
1. Откройте в браузере: **https://app.netlify.com/projects/dimastv-media/overview**
2. В рамку **«Already built it? Drop a folder, .zip, or HTML file»** перетащите файл **`dimastv-site.zip`** с Рабочего стола.
3. Готово! Сайт `https://dimastv-media.netlify.app` мгновенно обновится.
